# Consultatie API module Pagination bij Kennisplatform API's

In het kader van het beheer en de doorontwikkeling van [NLgov REST API Design Rules](https://gitdocumentatie.logius.nl/publicatie/api/adr) houdt Logius een openbare consultatie voor de API module Pagination.
Via deze consultatie nodigen wij u uit om feedback te geven op de standaard. De consultatie loopt tot **<EIND-DAG> <EIND-MAAND-UITGESCHREVEN> <EIND-JAAR>**.

Bij het Technisch Overleg (TO) API ([notulen](https://github.com/Logius-standaarden/Overleg/tree/main/API)) wordt gewerkt aan de eerste versie van de module Pagination.
Deze module standaardiseert het concept van pagination, legt daarbij vast welke naamgeving wordt gebruikt en welke velden moeten worden gebruikt.

Met deze consultatie binnen het Kennisplatform API's bieden wij belanghebbenden de gelegenheid om kennis te nemen van deze versie en te reageren op deze eerste versie.

## Reageren?

Feedback en suggesties zijn welkom via [issues](https://github.com/Logius-standaarden/API-mod-pagination/issues) op GitHub of te mailen naar [api@logius.nl](mailto:api@logius.nl).  
Help mee de eerste versie klaar te maken ter vaststelling.
